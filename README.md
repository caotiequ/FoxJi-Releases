# 狐小记 FoxJi

> 以项目为中心的待办软件 —— 不只记录"要做什么"，还记录"现在到哪了"

开发者：**MrCTQ** · 主页：[mrctq.com](https://mrctq.com)

## 简介

狐小记区别于市面主流"以待办为中心"的设计，采用**项目 → 待办 → 子待办**的三层结构，兼具轻量项目管理与笔记属性。客户端可纯本地单机使用，后续版本将支持连接自建服务端（FoxJi-Docker）进行多端同步。


## 下载

到右侧 **Releases** 下载最新版 zip，解压后运行「狐小记 FoxJi.exe」即可，免安装。

## 功能

### 项目模块

- 项目列表：名称 / 背景 / 当前情况 / 后续待办 一览，窄窗口自适应
- **状态时间线**：同一时间最多 1 个激活状态，可回溯项目"什么时间到什么时间处于什么状态"（为 AI 总结做数据准备）
- 网站管理：每个项目多条网站（备注+网址），列表一键用默认浏览器打开
- 项目备忘录：每项目一条富文本备忘录，随项目改名自动同步标题
- 删除项目时自选：下属待办/备忘录转独立或一并删除

### 待办模块

- 按项目分组展示，独立待办置顶
- 每条待办：内容 + 备注（当前进展/卡点）+ 开始/完成时间（滚轮时间控件可改）
- 提醒：系统通知，支持每天/每周循环
- 行内双击编辑、右键菜单（子待办/提醒/删除）、长按拖把手排序
- 筛选：全部 / 独立待办 / 项目待办 / 指定项目；已完成沉底

### 备忘录模块

- 列表 / 卡片双模式（记住选择），筛选与六种排序 + 手动拖拽排序
- 整页查看 / 原地编辑（无弹窗），轻量富文本
- **快捷复制框**：查看模式单击即复制；**超链接**：默认浏览器打开
- 绑定项目 / 独立备忘录

### 悬浮窗

- 桌面置顶小窗展示待办（含子待办、项目分组），可勾选完成、双击编辑
- 与主程序数据实时同步；独立主题、透明度、位置记忆、最小尺寸限制
- 右上角图标按钮：全部展开收起 / 显示隐藏已完成

### 全局

- 全局搜索：支持中文、**拼音全拼、拼音首字母**
- 全局快捷键：呼出主界面 / 开关悬浮窗 / 查看悬浮窗（最前↔最后），冲突自检提示
- 深色 / 浅色 / 跟随系统主题；系统托盘；开机自启（可仅启动悬浮窗）
- 数据导入导出（确认来源 + 覆盖/合并选择）
- 左侧栏折叠动画（图标零位移）

## 技术栈

- **Electron 33** + **Vue 3** + **Vite 5**
- 本地 JSON 文件存储（仅用户点保存时写盘）
- pinyin-pro（拼音搜索）
